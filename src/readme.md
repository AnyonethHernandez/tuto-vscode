hola lore
El lore es el conjunto de historias, antecedentes, mitos y detalles ocultos que dan forma y profundidad al 
universo de una obra de ficción (como videojuegos, películas o libros). En la jerga de internet y redes sociales, también se usa de forma divertida para hablar de la historia personal, las anécdotas o el pasado de una persona
